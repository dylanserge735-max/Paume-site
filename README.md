# PAUME ONG — Site web V5

Version mise à jour du site PAUME avec les 9 nouvelles photos de terrain fournies le 13 août 2026.

## Contenu
- Page d’accueil institutionnelle
- Menu mobile/desktop avec bouton « Nous soutenir »
- Pages : Qui sommes-nous, Domaines, Projets, Actualités, Galerie, Nous rejoindre, Soutenir, Rapports, Contact
- Galerie avec les 4 visuels d’action existants + 9 nouvelles photos de terrain
- Photos intégrées localement dans `assets/` : aucune dépendance à un hébergement d’images externe

## Utilisation
Ouvrir `index.html` dans un navigateur, ou déployer le dossier sur un hébergeur statique (Vercel, Netlify, GitHub Pages, etc.).
